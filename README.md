# Miaoying Li: civil engineering portfolio

Static site (no build step). Files:

- index.html: the page
- style.css, script.js: styling and the image viewer
- images/: all photos and screenshots
- .nojekyll: tells GitHub Pages to serve the files as they are

To publish on GitHub Pages, see the steps in the chat, or: create a public repo named `YOUR-USERNAME.github.io`, upload everything in this folder to the repo root, then turn on Pages (Settings > Pages > Deploy from a branch > main > / (root)).
